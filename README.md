# Family Feud: Survey Showdown

A Family Feud-style trivia game built with PHP, HTML, and CSS for CSC 4370/6370 (Fall 2026).

**Team:** Parker Saetang (Project Leader) and Melvin Dacanay

**Live site:** https://codd.cs.gsu.edu/~psaetang1/WEB/PW/PW2/

## Setup

1. Put the project folder in XAMPP's `htdocs` folder (or upload it to CODD).
2. Make sure `data/accounts.txt` exists and is writable (`chmod 666` on CODD).
3. Open `index.php` in your browser, register an account, and play.
